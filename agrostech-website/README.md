# Agrostech — Grow Smarter

A responsive, single-page agriculture technology company website. The design takes inspiration from the premium, dark, motion-led style of the Kelvaris Technologies site while using a distinct forest-green, cream, and lime identity for Agrostech.

## Included
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Hero, about, solutions, impact, field notes, contact form, and footer sections
- Scroll reveal animations and animated ticker
- Contact form validation that prepares an email in the visitor's email app
- SEO description, theme color, and custom SVG favicon
- Demo copy and illustrative stock photography

## Run locally
No build tools are required. Open `index.html` in a browser, or serve the folder with any static web server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` from this folder.

## Customize before publishing
1. Replace sample copy and sample editorial cards with verified company information.
2. Replace `hello@agrostech.example` in `script.js` with the real enquiry email address. The `.example` address is intentionally a placeholder.
3. Replace the remote Unsplash image URLs in `style.css` with approved company images if desired. Internet access is needed to load remote photos and Google Fonts.
4. Add a real backend or form service if enquiries need to be collected automatically. This demo prepares an email; it does not store submissions on a server.

## Publish
This is a static website and can be hosted on GitHub Pages, Netlify, or Vercel. Upload the contents of this folder (not the zip file itself) to your chosen static hosting workflow.
